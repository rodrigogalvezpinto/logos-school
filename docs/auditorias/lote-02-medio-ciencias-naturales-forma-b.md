## Observación P3 — pregunta 20: explicación del soluto

El enunciado pregunta cuál componente de una solución de agua con azúcar es el soluto. La pauta selecciona el azúcar, pero la justificación añade que lo es “porque está en menor cantidad y es la que se disuelve”.

La respuesta esperada es correcta para el ejemplo planteado; sin embargo, la cantidad relativa no define por sí sola qué sustancia es el soluto. La explicación debe priorizar que el azúcar es la sustancia disuelta en el agua. La frase actual puede inducir una regla simplificada demasiado general.

**Severidad:** P3 (mejora conceptual; no se encontró un error en la alternativa correcta para este caso).  
**Recomendación:** reformular la explicación, sin cambiar la clave, para que el criterio principal sea la función de cada componente en la solución.
