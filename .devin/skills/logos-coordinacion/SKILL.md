# Coordinación Logos School

Lee `.devin/agent-protocol.md` y las secciones vigentes del centro de control. No cargues todas las especificaciones ni perfiles por defecto.

1. Verifica Git y cambios locales; trabaja en main sin sobrescribirlos. Define un lote verificable, fuentes, curso/asignatura/OA, versión, permisos, entorno y aceptación.
2. Selecciona solo especialistas necesarios: logos-curricular para materia, logos-datos-evaluacion para importación/calificación, logos-qa-experiencia para ejecución visual/funcional, logos-desarrollador para correcciones y logos-seguridad-operacion según riesgo. El agente previo experto-examenes-libres se conserva para trámite administrativo; no duplica estos dictámenes.
3. Antes de delegar confirma disponibilidad real de perfiles. Si requieren recarga y no aparecen, informa el límite; una revisión con perfil incorporado como instrucciones no prueba que el perfil personalizado se ejecutó nativamente.
4. Paraleliza solo investigaciones independientes. Un responsable de escritura por archivo; fixtures aisladas para tests mutables. Encargos breves con evidencia/rutas como retorno; no agentes hijos ni equipos permanentes para tareas triviales.
5. Diagnosticar -> registrar -> corregir -> regresión -> revalidación independiente. Cambios críticos de claves/cálculos requieren segunda resolución. Nunca aprobar por conteo de archivos o resultados históricos.
6. Registra en centro de control y auditoría maestra, sin crear trackers paralelos. Separa dictamen educativo, datos/calificación, funcional/visual y seguridad; deja pendientes y bloqueos explícitos. No publiques ni hagas push por iniciativa propia.
