# Fuentes de los simulacros Forma A (tarea 8)

Cada script arma un `contenido/<curso>/examenes/<asignatura>-examen-forma-a.md` desde la Forma B del mismo curso
con `../forma_a.py`. El archivo de `contenido/` es la fuente de verdad; estos scripts quedan como registro y para
regenerar si se corrige la Forma B (encabezado o cola). Si se edita el `.md` a mano, no volver a correr el script.

Nombre: `<asignatura><curso>.py` (h = Historia, l = Lenguaje/Lengua, i = Inglés, m = Matemática, c = Ciencias).
Matemática y Ciencias Naturales de 5.° básico se armaron a mano (sin script).
